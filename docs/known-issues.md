# Known Issues

These are acknowledged bugs, unfinished pieces, or deliberate exclusions in the OpenFit app.

If you find something that isn't here, please [file an issue](https://github.com/open-source-fitness/open-fit/issues/new?template=bug_report.md)!

*Last Updated: Nov 25, 2026*

## Bugs

No known bugs yet. We know they are out there, so please [report them](https://github.com/open-source-fitness/open-fit/issues/new?template=bug_report.md) when you find them!

## Unfinished pieces

Device testing is currently only being done using Expo Go development builds. Until developer profiles can be acquired for build signing, true on-device offline testing cannot be done

## Deliberate exclusions

For the time being, the following common features have been excluded from the roadmap to focus on the core feature of the app:
- Workout sharing/collaboration feature
- Height/weight input to cater training suggestions
- AI assistant features

This does not mean the app will never have these features, but for now they are being left out.
