# Onboarding guide

1. **What is OpenFit working toward?** See the [roadmap](./roadmap.md) for the MVP and planned releases.
2. **How do I run and test the app?** Follow the [setup guide](./setup.md) to install dependencies, launch the app, and run checks.
3. **What can I work on?** Look for a Ready task on the [OpenFit MVP project board](https://github.com/orgs/open-source-fitness/projects/1). The [project management guide](./project-mgmt.md#labels-and-choosing-work) explains how to choose a task.
4. **Where do I ask questions or request an assignment?** Follow the [communication standards](./communication-standards.md) for GitHub Discussions and issue conversations.
5. **How do I submit a change?** Read the [contributing guidelines](../CONTRIBUTING.md) and [Git standards](./git-standards.md#pull-requests) for pull requests and review.
